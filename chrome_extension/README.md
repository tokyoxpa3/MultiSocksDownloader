# 多代理下載器 Chrome 擴展程式

這個 Chrome 擴展程式可以攔截 Chrome 的下載事件，並將下載連結傳遞到多代理下載器應用程式，實現使用多個代理同時下載文件的功能。

## 功能特點

- 攔截 Chrome 的下載事件，自動將下載連結傳遞到多代理下載器
- 轉送瀏覽器的 Cookie / Referer / 使用者代理，讓需要登入或防盜連的直連檔也能被抓取
- 提供右鍵選單，可以選擇使用多代理下載器下載特定連結
- 提供「站點黑名單」：把特定網站加入黑名單後，該站改用瀏覽器原生下載，不再攔截
- 通過 HTTP 與多代理下載器應用程式通信
- 可以在擴展程式彈出視窗中配置和測試連接

## 安裝步驟

### 1. 安裝 Chrome 擴展程式

擴展程式以「開發者模式／未封裝」方式載入。在開始前，請先確認：

- 已安裝 Google Chrome（或以 Chromium 為核心的瀏覽器，如 Microsoft Edge）
- 多代理下載器應用程式可正常啟動（擴展程式需透過本機 HTTP 與它通信，預設連接埠 `8765`）

以下提供兩種安裝方式。

#### 方式一：一鍵安裝腳本（推薦）

在專案根目錄雙擊執行 `install_extension.bat`，腳本會自動：

1. 把擴展檔案複製到穩定位置 `%LOCALAPPDATA%\MultiSocksDownloader\chrome_extension`
2. 開啟 Chrome，並嘗試自動導向擴展程式管理頁面 `chrome://extensions/`
3. 在命令列視窗中印出需要選擇的資料夾路徑

接著只需在 Chrome 頁面手動完成最後三個步驟：

1. 開啟右上角的「開發者模式」
2. 點擊「載入未封裝項目」
3. 在檔案選擇視窗中，選取腳本印出的資料夾路徑：
   `%LOCALAPPDATA%\MultiSocksDownloader\chrome_extension`

> **為什麼要複製到 `%LOCALAPPDATA%`？**
> Chrome 會記住你載入資料夾的絕對路徑。如果直接從專案目錄載入，之後搬移或刪除專案，擴展程式會因找不到檔案而失效。複製到 `%LOCALAPPDATA%` 下的獨立資料夾可避免此問題。

> **找不到 Chrome 時**：腳本會顯示警告，此時請手動開啟瀏覽器並前往 `chrome://extensions/`。

#### 方式二：手動安裝（開發模式）

1. 開啟 Chrome，在網址列輸入 `chrome://extensions/` 並按 Enter
2. 開啟右上角的「開發者模式」開關
3. 點擊「載入未封裝項目」
4. 選取專案中的 `chrome_extension` 資料夾。請務必選取**直接包含 `manifest.json` 的那一層**，而不是專案根目錄或更上層資料夾
5. 載入成功後，擴展程式卡片上會顯示名稱「多代理下載器」與一組擴展程式 ID

> **注意**：方式二直接從專案目錄載入，若日後搬移或刪除專案，擴展程式會失效。如需長期使用，建議改採方式一，或先把 `chrome_extension` 複製到固定路徑再載入。

### 2. 驗證安裝結果

1. 在 `chrome://extensions/` 頁面確認「多代理下載器」卡片存在，且沒有紅字的「錯誤」或「無法載入」提示
2. 點擊瀏覽器工具列右側的拼圖圖示（擴充功能選單），將「多代理下載器」釘選到工具列，方便日後隨時開啟設定面板
3. 先啟動多代理下載器應用程式，再點擊工具列上的擴展圖示，確認彈出視窗正常開啟並顯示「連接狀態」

### 3. 常見安裝問題

- **載入後顯示「無法載入」或紅色錯誤**：通常是選錯資料夾（選到專案根目錄或上一層）所致。請確認選取的資料夾內直接包含 `manifest.json` 與 `background.js`。
- **腳本沒有自動開啟管理頁面**：腳本透過模擬鍵盤輸入網址，偶爾會因視窗焦點問題失敗。請手動在 Chrome 網址列輸入 `chrome://extensions/` 即可。
- **擴展程式莫名失效或消失**：若曾以方式二從專案目錄載入，專案被搬移後擴展會一併失效。改用方式一複製到固定位置可解決。

## 使用方法

### 1. 啟動多代理下載器應用程式

在使用擴展程式之前，請確保多代理下載器應用程式已經啟動。

### 2. 使用擴展程式

擴展程式提供兩種使用方式：

#### 自動攔截下載

當您在 Chrome 中點擊下載連結時，擴展程式會自動攔截下載事件，並將下載連結傳遞到多代理下載器應用程式。

#### 右鍵選單下載

您也可以在任何連結上點擊右鍵，選擇「使用多代理下載器下載」選項，將該連結傳遞到多代理下載器應用程式。

#### 站點黑名單

有些檔案站（例如 WDFiles 等）的檔案是透過倒數計時、一次性簽名 token 與 IP 綁定來提供，攔截後重新抓取無法取得檔案。遇到這種網站，可在該網頁任意空白處點擊右鍵，選擇「將此網站加入下載黑名單」，此後該站的下載會改用瀏覽器原生方式進行，不再被攔截。

- 加入／移出：在目標網頁上點擊右鍵，選「將此網站加入下載黑名單（改用瀏覽器原生下載）」即可切換。
- 管理清單：點擊工具列圖示開啟彈出視窗，在「下載黑名單」區塊可檢視並移除已加入的網站。

### 3. 配置擴展程式

點擊瀏覽器工具欄上的擴展程式圖標，可以打開配置面板：

- 啟用/禁用下載攔截：控制是否自動攔截所有下載
- 應用程式伺服器地址：設置多代理下載器應用程式的 HTTP 伺服器地址
- 測試連接：檢查與應用程式的連接狀態
- 儲存設定：保存當前配置
## 故障排除

### 擴展程式無法連接到應用程式

1. 確保多代理下載器應用程式已啟動
2. 檢查應用程式伺服器地址是否正確（預設為 `http://localhost:8765`）

### 下載未被攔截

1. 確保擴展程式已啟用下載攔截功能（點擊工具列圖示，確認「啟用下載攔截」開關為開啟）
2. 檢查擴展程式是否有足夠的權限
3. 嘗試使用右鍵選單方式下載

## 開發者信息

- 擴展程式使用 Manifest V3 開發
- 擴展程式需要以下權限：
  - `downloads`：用於攔截下載事件
  - `contextMenus`：用於添加右鍵選單
  - `storage`：用於存儲設置與站點黑名單
  - `notifications`：用於顯示下載通知
  - `cookies`：用於讀取瀏覽器 cookie，轉送給應用程式以抓取需要登入／防盜連的直連檔
  - `host_permissions`（`<all_urls>`）：讓擴展程式能讀取所有網站的 cookie；若不需此能力，可在 `manifest.json` 中收窄為特定網域
